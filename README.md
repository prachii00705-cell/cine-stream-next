# Cine Stream

Movie discovery web app built with Next.js 15 and TMDB API.

## Features

- Browse Popular Movies
- Search Movies
- Movie Details
- Watch Trailer
- Favorite Movies
- Responsive Design
- SEO Metadata
- Loading UI
- Error Handling

## Tech Stack

- Next.js 15
- React
- TMDB API
- CSS
